1. Create `backend/socket_handlers.py` — registers Socket.IO event handlers on the `sio` object from main.py.

The file must:
- Import `sio` from `backend.main`
- Register handlers for Motor Pi inbound events using exact event names from `server_bridge.py`
- Each handler writes to DB via crud functions and emits broadcast events per D-04

Event handlers to register:

**@sio.on("connect"):**
- Log connection: `print(f"[SocketIO] Client connected: {sid}")`

**@sio.on("disconnect"):**
- Log disconnection: `print(f"[SocketIO] Client disconnected: {sid}")`

**@sio.on("state_change"):**
- Receives: `{'node_id': str, 'state': str}`
- Action: Log the state change via `crud.create_log()` with level="INFO", event_type="state_change"
- Broadcast: `await sio.emit('job_state_update', {'session_id': None, 'status': data.get('state', 'unknown'), 'node_status': {}})`
- Uses `db_session()` context manager directly (not Depends — this is async handler, not FastAPI route)

**@sio.on("complete"):**
- NOTE: Motor Pi emits 'complete' not 'execution_complete' (server_bridge.py line 49)
- Receives: `{'node_id': str, 'status': 'success'|'failed'}`
- Action: Log via `crud.create_log()` with level="INFO", event_type="execution_complete"
- Broadcast: `await sio.emit('job_state_update', {'session_id': None, 'status': 'done' if data.get('status') == 'success' else 'error', 'node_status': {}})`
- Add comment: `# Motor Pi emits 'complete' — see motorctl/src/server_bridge.py line 49`

**@sio.on("log"):**
- Receives: `{'node_id': str, 'msg': str}`
- Action: Log via `crud.create_log()` with level="INFO", event_type="node_log"

**@sio.on("heartbeat"):**
- Receives: `{'node_id': str, 'node_type': str, 'status': str, ...}`
- Action: Call `crud.upsert_heartbeat()` with NodeStatusUpsert (last_heartbeat = datetime.now(timezone.utc))
- Broadcast: Emit `job_state_update` with updated node_status dict from `crud.get_all_nodes()`

All handlers are `async def` since `sio.emit()` is async. DB access uses `with db_session() as conn:` (synchronous context manager is fine inside async handler since SQLite operations are fast and non-blocking at this scale).

Test fixtures for backend API integration tests.
Pattern: tempfile DB + create_tables + TestClient(fastapi_app).

import tempfile
import pytest
from fastapi.testclient import TestClient

import database.db as db_module
from database.init_db import create_tables
from backend.main import fastapi_app  # NOT app (the socketio.ASGIApp)


@pytest.fixture
def client():
    """Each test gets a fresh SQLite DB + TestClient wrapping fastapi_app only."""
    with tempfile.NamedTemporaryFile(suffix=".db", delete=False) as f:
        db_path = f.name
    os.environ["DATABASE_URL"] = db_path
    db_module.DB_PATH = db_path
    conn = db_module.get_db()
    create_tables(conn)
